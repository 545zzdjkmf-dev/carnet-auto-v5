Synchronisation iCloud — étape de configuration

Cette version améliorée est prête pour une configuration CloudKit, mais la synchronisation iCloud n'est pas encore active. Il faut créer/configurer un conteneur Apple, activer CloudKit JS et l'authentification web, puis intégrer les identifiants propres à ton compte. Ne colle jamais un secret serveur dans le code d'une PWA.
  1. Sur le Mac, ouvre le portail développeur Apple et vérifie l'accès à CloudKit Console.
  2. Crée un conteneur iCloud et configure son schéma dans CloudKit Console.
  3. Active les services Web et l'authentification utilisateur selon la documentation officielle.
  4. Une fois le conteneur configuré, l'application doit recevoir un module CloudKit adapté, puis être testée sur l'iPhone et l'iPad avec le même compte Apple.

Documentation officielle CloudKit JS · CloudKit Console

Les données publiques officielles sont publiées par le gouvernement, avec un flux instantané annoncé comme actualisé à moins de 10 minutes.
